# RFU---FS25_RealisticFuelUsage
Farming Simulator 25 mod - This mod make fuel usege more realictic.

Realistic Fuel Usage adjusts the base diesel consumption of motorized vehicles to provide more believable fuel usage in Farming Simulator 25.
Instead of relying on the widely varying fuel consumption values defined by individual vehicle mods, RFU calculates a standardized base consumption according to the engine power of the selected vehicle configuration.
The mod is designed to work universally with both base-game vehicles and properly configured mod vehicles. It does not contain vehicle-specific presets and is not tied to any particular map or modpack.

Features:
• Automatically adjusts diesel consumption based on engine power
• Uses the selected vehicle's configured power rating when available
• Supports base-game and modded vehicles
• No vehicle-specific configuration required
• Compatible with multiplayer
• Does not modify fuel prices, refueling mechanics or vehicle performance
• Designed to remain compatible with other gameplay and realism mods
The current consumption target is approximately 0.190 liters per hour per horsepower at full base consumption, while the game's own engine load and consumption systems continue to determine the actual instantaneous fuel usage.

Installation
Place FS25_RealisticFuelUsage.zip into your Farming Simulator 25 mods folder and activate the mod for your savegame.
